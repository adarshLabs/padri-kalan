# Photos folder

Put village photos here, for example `baleshwari-mandir-front.jpg`.

1. Only use photos you took yourself, or that the photographer gave written permission for (a WhatsApp message is fine; keep it).
2. People in the photo must agree. Children only with a parent's agreement.
3. Make them small: about 1200 pixels wide, under 300 KB (use squoosh.app, free).
4. Add an entry in `data/gallery.json` with the photographer's name and the licence (CC BY-SA 4.0 is suggested), and set `"permission": true`.
5. Bump `VERSION` in `sw.js`.

Never copy photos from Google Images, Google Maps, Facebook, Instagram, YouTube or news websites: they are copyrighted.
